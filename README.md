An entry for the [Seventeen Syllables of Debugging](https://make.fun/c/u-irvan-motion-seventeen-syllables-of-debugging-d194b605) competition on [make.fun](https://make.fun).

## What it does

`main.py` (Python 3.13, standard library only) writes one original haiku
about debugging — three lines in the 5-7-5 syllable shape — to
`/output/entry.txt`:

```text
Breakpoint holds its breath
the log line swears all is well
and the bug was me
```

## Run

```sh
python3 main.py
cat /output/entry.txt
```
